# Lunar Lander
Deep Reinforcement Learning for Autonomous Lunar Landing
This repository features a complete, end-to-end implementation of the Policy Gradient method (REINFORCE) using PyTorch and Gymnasium to train an intelligent agent to safely land a spacecraft in the LunarLander-v3 simulation environment.

🛠️ Technical Architecture
Algorithm: REINFORCE (Monte Carlo Policy Gradient) optimized with state-independent baseline subtraction and variance reduction via reward normalization.
Neural Network: Deep Policy Network engineered in PyTorch (Fully Connected layers, ReLU activations, Categorical Action Distributions).
Environment: OpenAI/Gymnasium Box2D physical simulation (8-dimensional continuous vector input, 4 discrete output actions).
Visualization & Deployment: Dynamic rendering pipeline exporting MP4 video episodes optimized for web/notebook playback via FFmpeg.
